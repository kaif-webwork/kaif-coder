# Mohd Kaif | Full Stack Developer | Portfolio 🚀

Official personal developer portfolio of **Mohd Kaif** ([@kaif_coder](https://x.com/kaif_coder)) hosted at **[kaifcoder.in](https://kaifcoder.in)**.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, React Router 7, Vite
- **Animations & Effects:** GSAP (Pixel Transition), Canvas (ClickSpark)
- **Visuals & Charts:** Apache ECharts, React Icons
- **Backend & APIs:** Vercel Serverless Functions, Upstash Redis
- **Styling:** Modular Vanilla CSS & Design Tokens

## 🚀 Features

- ⚡ Ultra-fast performance with Vite & zero runtime overhead
- 🎨 Custom interactive pixel dissolution transitions with sound effects
- 📱 Fully responsive Play Store style showcase for projects (AdZero)
- 🔍 Optimized SEO with Open Graph, Geo-tags, and Schema.org JSON-LD Graph
- 🔒 Safe multi-network Crypto & UPI contribution hub

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/kaif-webwork/kaif-coder.git

# Install dependencies
npm install

# Run dev server
npm run dev

# Production build
npm run build
```
